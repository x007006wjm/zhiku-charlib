# 智库 · SillyTavern 扩展

作者 **if love** · 版本 **0.8.36**。NovelAI 生图、画师库、例图、角色、衣柜、标记生图与共享上传。

## 安装与更新

1. 打开酒馆「扩展」→「安装扩展」。
2. 粘贴仓库地址：`https://github.com/ruoege49-ship-it/zhiku-tavern-helper`
3. 安装后刷新酒馆，通过扩展设置「打开智库」、魔棒菜单「智库」或侧边票根打开。
4. 后续在扩展管理里点击更新，再刷新页面。

扩展版不需要酒馆助手。最低宿主版本为 SillyTavern 1.14.0；新版本宿主支持启停钩子，旧版本启停后刷新页面。

**从脚本版切换：先停用酒馆助手脚本库中的旧「智库」，再启用扩展版。** 同一个酒馆用户下，原有画师库文件、图片、NovelAI 设置与共享身份继续沿用，无需重新导入画师库。

## 共享

共享页右上角「＋ 上传」可填写名称、署名、画师串、标签和说明，并附上最多 6 张例图。发布后自动打开「我分享的」。内置共享服务器地址，无需邀请码。已有自定义服务器地址优先使用。NovelAI Key 由使用者自己在酒馆内配置。

## 文生图标记与不发送正则

回复中使用完整标记：

```text
image###1boy, solo, sunset, cinematic lighting###
```

自动使用标记里的提示词调用 NovelAI，结合当前画师串、质量设置及参考图配置；不另外请求聊天 AI 改写剧情。生成结果单独保存在消息扩展数据中，按标记位置显示；原消息与提示词保留，同楼多个标记按顺序生成。普通回复不会自动生图。标记默认显示为收起的「图片提示词」，旁边有「生成图片」按钮，可单独生成该标记；生成中禁用按钮，失败后可点击「重试生成」。魔棒菜单使用 与酒馆一致的单色图片图标。

「开启标记自动生图」默认开启，位于智库设置的「文生图标记」中，也可直接在酒馆的智库扩展设置中切换；关闭选择会保存。开始与结束标记在「文生图标记」中调整。若安装过智绘姬，默认读取它的 `startTag` / `endTag`；否则使用 `image###` / `###`。回复还在流式输出时，标记一写完整就先生图（见下）。重复消息渲染不会重复生成；切换聊天或改写消息后，不把在途图片插到其他楼层。

内置并自动注册 **「智库 · 生图标记不发送」** 正则：仅过滤发给聊天模型的用户／角色消息文本，保留聊天原文供生图识别。另有「智库 · 生图标记折叠」显示正则，负责折叠块；两条规则都保留编辑原文。修改开始、结束标记时正则同步更新。原有其他正则保留。此功能使用酒馆自带的 Regex 扩展，请保持它启用。

旧的「每楼自动生成」已移除。没有标记的旧楼不会因升级或重新打开聊天而自动扣点。失败时保留标记，可以通过楼层图片按钮重试。


### 流式预生成

默认开启。回复还在流式输出、`image###` 与 `###` 已经闭合的那一刻就把生图请求发出去，等正文写完时图片往往已经好了。只认闭合的标记，半截的标记不动。消息落地时能对上（同一楼、同一段标记）就直接复用，对不上就重新生成一次，不会留下两张。关掉这个开关就退回原来的「消息完成后识别」。

### 生成后自动展开

默认开启。这次刚生成的图片自动展开，历史图片仍按「图片默认展开」的设置显示，不会被一并拉开。

## 角色外观库

让 AI 在回复里顺手建档，之后生成的每张图都按当时的档案描外貌，前后楼层自动对得上。

自动建档用两个代码块，写在回复正文里即可，写完在正文里折叠显示，不会发给聊天模型：

```text
<人物>
名字: 小雨
别名: 小雨点|Ame
外貌: 1girl, short black hair, red eyes
衣服: blue raincoat
描述: a quiet girl, always holding a notebook
</人物>
```

- `名字` 必填；`别名` 用逗号、顿号、分号或竖线隔开，图片标记里写名字或别名都认。
- `外貌`、`衣服` 按标签写；`衣服: 跟剧情`（或 `story`）表示不固定。
- `描述` 是英文整句，会接在角色标签后面进 NovelAI 的分角色 caption。

外貌变动用 `<外貌变化>`，字段是 `名字` 加 `加:` / `去:` / `外貌:` / `衣服:`，可带 `原因:`。

```text
<外貌变化>
名字: 小雨
加: red eyes
原因: 觉醒
</外貌变化>
```

- 按楼层生效：后面的楼层都按新档案，前面的楼层不受影响。
- 按位置生效：`<外貌变化>` 只影响它后面那些图片标记，同一楼里写在它之前的标记仍用旧档案。
- `<人物>` 只影响它所在这一楼及之后。

两层库：

- **全局角色库**（角色页维护）对 AI 只读，AI 写同名块会被忽略，只能手动改。
- **本聊天角色库**优先，按字段回落：本聊天只写了外貌，就沿用全局的服装与描述。
- 角色页有「本聊天角色」入口：新建、编辑、看历史、回滚、提升为全局、把全局复制一份过来。手动改过之后，早先楼层写的变化会收进历史。

宏 `{{zhiku_characters}}` 输出当前出场角色的档案清单（名字、别名、固定服装，全局库的标「固定，不可改」），可以放进世界书或提示词让主 AI 参考。

开关在「文生图标记」下面：自动建档、建档提示、生成后自动展开、流式预生成。

### 逐图角色标记

先在角色页登记外貌和名字／别名，并在「这次聊天」启用。例如本图只画小红和小蓝：

```text
image###2girls, garden, $小红-sfw-upperbody$, smiling, $小蓝-sfw-upperbody$, waving###
```

JSON 写法也能识别角色：

```text
image###1girl, garden, ${"name":"小红","angle":"from front","upperBody":"sfw","lowerBody":"hidden"}$, smiling###
```

此适配读取智库里保存的外貌、固定衣服和参考图；`angle` 进入该角色的提示词。智库现有角色数据没有智绘姬的上下半身独立字段，身体状态后缀用于识别协议，不会按部位重建外貌或衣服。需要不同衣着时，在智库衣柜或该图标签里设置。

没有角色的空镜直接写 `image###no humans, lake, sunset###`。普通英文标签无需加角色标记；`$小红$` 裸名字不属于有效格式。

使用自定义世界书／外部生图预设时，在原有规则中补上这一段即可，张数继续由原有玩家设置控制：

```text
每张图片只描绘一个瞬间。对该图实际入画、已在智库登记并启用的角色，在 image###...### 内逐人写 $角色名字-sfw-upperbody$，随后写该角色当下的英文动作、表情等标签。未入画的人不写标记，空镜不写角色标记。角色名字可用中文，其余画面标签用英文。没有登记的角色直接写英文外貌标签。图片数量沿用玩家设置。
```

## 绑定与切换

- 角色卡绑定画师串：进入该角色的聊天自动切换；离开到没绑定的角色时，换回绑定前在用的画师串。
- 「只用一次」「每生成一张就换一个」在聊天里每出一张标记图后生效。
- 角色参考只在「角色」页给每个角色单独绑（建组、加图、调「像不像」都在那里）；标记生图时按出场角色带上，没绑就不用。氛围页只管氛围。

## 生图队列

手动点击仅生成对应标记；多个标记时楼层入口提示选择具体按钮。每张独立显示排队、生成、保存状态。智库内普通生图、局部重绘和氛围编码共用串行队列，请求间隔至少 1.5 秒；429 按 Retry-After 或 5/10 秒退避，最多重试两次。用酒馆里的 NovelAI key 时，酒馆会把 429 报成 500，这种情况同样等待后重试。当前队列仅协调本页面智库，不包含智绘姬的跨设备云端队列。
